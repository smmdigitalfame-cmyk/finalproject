# Student Reels Lab

An independent student project for learning short-video interfaces, media handling and analytics visualization. Not affiliated with, endorsed by, or operated by TikTok or ByteDance. No fees are charged for this learning project.

## Data and access disclosure

- Fetched public video/profile data is distinct from locally edited or estimated insights. Estimated watch time, completion, traffic and audience figures are educational values, not verified official platform analytics.
- Access uses project keys generated by the administrator's Telegram bot. Never enter a TikTok password, verification code or payment details.
- Access attempts may be recorded and sent to project administrators via Telegram, including the access key used, IP address, device information and time.
- Use only media and accounts you have permission to use, and respect provider terms and applicable law.
- Educational wording is not a guarantee against browser or hosting security warnings. Any warning must be investigated and appealed honestly through the relevant provider.

## Independent hosting

The current deployment targets Lovable's Cloudflare runtime. Exporting code does not migrate database records, media storage, private credentials or provider connections, and does not make this version Vercel-ready. Independent hosting requires a compatible deployment target, your own backend configuration and securely configured server credentials. Never commit `.env` files, access tokens or private keys.
