# Student Reels Lab

An independent student project for learning short-video interfaces, media handling and analytics visualization. Not affiliated with, endorsed by, or operated by TikTok or ByteDance. No fees are charged for this learning project.

## Data and access disclosure

- Fetched public video/profile data is distinct from locally edited or estimated insights. Estimated watch time, completion, traffic and audience figures are educational values, not verified official platform analytics.
- Access uses project keys generated by the administrator's Telegram bot. Never enter a TikTok password, verification code or payment details.
- Access attempts may be recorded and sent to project administrators via Telegram, including the access key used, IP address, device information and time.
- Use only media and accounts you have permission to use, and respect provider terms and applicable law.
- Educational wording is not a guarantee against browser or hosting security warnings. Any warning must be investigated and appealed honestly through the relevant provider.

## Independent hosting

Independent builds target Vercel. Apply SQL migrations in filename order, then `deploy/independent-database.sql`, to your own backend. Configure a public `media` bucket without anonymous write policies. Set build-time `VITE_SUPABASE_URL`, `VITE_SUPABASE_PUBLISHABLE_KEY`, and `VITE_SUPABASE_PROJECT_ID`. Set server-only `SUPABASE_URL`, `SUPABASE_PUBLISHABLE_KEY`, `SUPABASE_SERVICE_ROLE_KEY`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, `ZYLA_API_KEY`, and `RAPIDAPI_KEY`. Uploads use active project keys and signed direct-to-storage transfers. Configure Telegram's webhook with its secret header after deployment. Code export does not migrate records, media or credentials. Never commit `.env` files, access tokens or private keys.

This project was built with [Lovable](https://lovable.dev).

**Independent live app**: https://finalproject-six-mu.vercel.app

Zyla is the primary scraping service, with RapidAPI as backup. The optional third Apify fallback requires a direct `APIFY_API_KEY` in the hosting environment; no Lovable gateway credential is required. The existing Telegram bot now serves this independent deployment. Generate new keys using `/gen name 30` or `/gen name lifetime`; keys from the former backend are not automatically imported.
